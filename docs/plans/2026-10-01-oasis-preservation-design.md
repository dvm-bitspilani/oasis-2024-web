# Approved Oasis 2024 preservation scope

Preserve the original Regal Roulette artwork, typography, slot machine, trees, navigation, responsive category art, artist content and animations. Remove all added portfolio and demo wording and simulated registration. Every registration control opens the same small native dialog stating “Registration is closed for this edition”, with a close button, Escape support, native focus containment and focus return. Direct registration and former dashboard URLs retain the original roulette artwork and open that dialog.

Do not invent missing historical event or sponsor records. Keep the original category artwork, headings, backgrounds and routes where the retired backend supplied no records. Keep mobile events and shows on their original responsive routes.

Keep the static Next export and patched lockfile dependencies. Separate the events route from the landing client entry, prefetch on pointer, keyboard or touch intent, display original artwork while loading, prioritize critical media and defer audio until playback. Retain full tracks as compressed Opus assets. Keep original slot art visible until the locally decoded 3D model is ready; use that artwork for reduced motion, unsupported WebGL and context loss. Keep strict external bootstrap scripts, native local Draco, immutable caching for hashed assets and revalidation for documents.

Verify the locked build, TypeScript, lint, dependency audit and all emitted routes, resources, script hashes and headers. Browser and remote checks are coordinated by the parent agent.
